# cc-rail-path

铁路区间与车站运行资源管理服务：货运列车跨多个区间和车站预留完整运行径路。

## 开发环境

- JDK 21
- Maven Wrapper 3.9.9
- Spring Boot 4.1.1（JPA + H2 + Bean Validation）

迁移项目沿用现有 Spring Boot 版本，其他项目使用上述版本。

## 常用命令

运行测试：

    ./mvnw clean test

启动服务：

    ./mvnw spring-boot:run

## 领域模型

- **区间（Section）**：编号唯一，记录方向（UP/DOWN）、通过能力（同一时间允许占用的列车数）和最小追踪间隔（分钟）。
- **车站（Station）**：编号唯一，记录可用到发线数量。
- **径路（TrainPath）**：一次批准即整体生效的区间占用（PathLeg）与车站停靠（PathStop）集合，以外部运行号为幂等键。
- **事件（PathEvent）**：批准、改线、取消的不可变记录，只插入不更新，detail 保存发生时点的径路快照。

## 主要业务规则

1. **径路申请**：按顺序给出计划经过的区间（进入/离开时间）和需要停靠的车站（到达/出发时间）。
2. **时间连续性**：每个区间进入时间必须早于离开时间；相邻区间按时间顺序排列且不重叠；停靠时间必须位于整条径路的时间窗内且互不重叠。
3. **容量约束**：
   - 区间：任意时刻同时占用列车数不得超过通过能力；且与同一区间既有占用的进入/离开时间差不得小于最小追踪间隔。
   - 车站：任意时刻同时停靠列车数不得超过可用到发线数量。
4. **原子批准**：申请在单个事务内先校验全部节点，再一次写入全部区间与车站占用；任一节点冲突即整体回滚，不留下部分径路。
5. **幂等**：以外部运行号为幂等键（数据库唯一约束兜底）。相同编号、相同内容的重放返回原结果（HTTP 200）；编号相同但内容不同返回冲突（HTTP 409 CONFLICT）。
6. **并发控制**：审批/改线时按编号升序对涉及的区间、车站行加悲观写锁（`SELECT ... FOR UPDATE`），并发争抢同一区间时只有符合容量限制的组合能成功。
7. **整体改线**：仅未发车（首个区间进入时间在未来）的有效径路可改线。新径路完整通过校验并写入占用后才释放旧径路；任一步失败事务回滚，原计划不变。
8. **取消**：释放全部占用，径路状态置为 CANCELLED，事件保留；重复取消返回状态错误。
9. **统一错误**：校验错误（400 VALIDATION_ERROR）、资源不存在（404 RESOURCE_NOT_FOUND）、容量不足（409 CAPACITY_EXCEEDED）、追踪间隔不足（409 HEADWAY_VIOLATION）、幂等/约束冲突（409 CONFLICT）、状态不允许（409 INVALID_STATE），响应体统一为 `{"code", "message", "details"}`。

## API 一览

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/sections` | 登记区间（编号、方向、通过能力、最小追踪间隔） |
| GET | `/api/sections` | 区间列表 |
| POST | `/api/stations` | 登记车站（编号、到发线数量） |
| GET | `/api/stations` | 车站列表 |
| POST | `/api/paths` | 申请径路（幂等：重放返回原结果，内容不同返回冲突） |
| GET | `/api/paths/{ref}` | 查询径路完整占用明细 |
| GET | `/api/paths/{ref}/events` | 查询批准/改线/取消事件流 |
| POST | `/api/paths/{ref}/reroute` | 整体改线（新径路完整取得后才释放旧径路） |
| POST | `/api/paths/{ref}/cancel` | 取消径路并释放全部占用 |

申请示例：

```json
POST /api/paths
{
  "externalRef": "T-1001",
  "legs": [
    {"sectionCode": "S1", "enterTime": "2030-06-01T08:00:00", "exitTime": "2030-06-01T08:20:00"},
    {"sectionCode": "S2", "enterTime": "2030-06-01T08:20:00", "exitTime": "2030-06-01T08:45:00"}
  ],
  "stops": [
    {"stationCode": "ST1", "arriveTime": "2030-06-01T08:10:00", "departTime": "2030-06-01T08:12:00"}
  ]
}
```
